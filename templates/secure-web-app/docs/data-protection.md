# How data is protected

What kinds of information this app is set up to handle, and what protects it.

## Data this app is designed to hold

No data categories were specified at design time; treat any personal information you add as sensitive by default.

## Protections that apply to every record

- Every list query has an upper bound (no query returns unlimited rows).
- Only DTOs (chosen fields) are ever sent to a page or the API — a raw database row is never returned.
- Fields an entity marks `sensitive` are encrypted at rest (AES-256-GCM, see docs/crypto.md) and redacted from logs. Field encryption is switched on.
