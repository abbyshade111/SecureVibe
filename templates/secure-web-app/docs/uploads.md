# File uploads

File uploads are currently switched off (`uploads` is not enabled in securevibe.features.json). The rules below apply if it is turned on.

| Rule | Value |
| --- | --- |
| Largest file accepted | 10 MB |
| Allowed types | `image/png`, `image/jpeg`, `image/gif`, `image/webp`, `application/pdf` |
| Storage limit per user | 200 MB |
| Where files are stored | Outside the web root, under a random file name; never at a path a visitor can guess or choose |
| How the type is checked | The file's first bytes are checked against a known table (not just the file name or the browser's claimed type); mismatches are refused |
| Types that are always refused | `svg`, `html`, `xml`, `zip` — regardless of the allow-list above, because they can contain active content |
| Downloading a file | Sent with `Content-Disposition: attachment`, `X-Content-Type-Options: nosniff` and a sandboxed content policy; only the file's owner (or an administrator) may download it |
