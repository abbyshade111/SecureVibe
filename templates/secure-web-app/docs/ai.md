# The AI assistant

The AI assistant is currently switched off (`ai` is not enabled in securevibe.features.json). The rules below apply if it is turned on.

## The model this app uses

| Setting | Value |
| --- | --- |
| Provider | Anthropic (the `@anthropic-ai/sdk` package, called from `src/features/ai/client.ts` and nowhere else) |
| Model | `claude-opus-5` (pinned — never chosen by the model itself or by a visitor) |
| Instructions | fixed in `src/features/ai/prompt.ts`, fingerprint `272da6546d315c89…` (recorded with every request) |
| Answer shape | a fixed structure (answer, refused, reason); anything else is replaced by a standard message |
| Longest question accepted | 8000 characters (longer input is refused, never cut short) |
| Longest answer | 1024 tokens, and at most 4000 characters |
| Time limit per call | 30 seconds |
| Daily budget per user | 200000 tokens |
| Requests per user | 20 an hour |
| Content moderation | Off |
| Conversation memory | Not kept |
| Kill switch | AI_ENABLED=0 in .env, or an administrator can switch it off at runtime; both are logged |

## What the assistant can see

Only data that belongs to the person asking, fetched through the app's normal data-access functions — never a raw database query built from the question. Anything it reads is clearly marked as untrusted data, separate from its instructions, so text inside a record cannot make it act differently, and it is screened with the same list of manipulation patterns as the question.

Before an answer is shown it is checked again: it must match the expected shape and length, it must not repeat the assistant’s own instructions, and any record identifier or email address belonging to somebody else is removed. The answer is shown as plain text — never as HTML, markdown or a link.

## What the assistant can do

| Action | What it does | Needs confirmation |
| --- | --- | --- |
| `list_my_records` | Lists the records that belong to the person asking, so their question can be answered from them. | No (reading only) |
| `create_note` | Proposes a new note for the person asking. Nothing is saved until they confirm it. | Yes — a person confirms it before anything happens |

Actions are switched off in this app: the assistant can only answer questions.

## What is recorded

Every call is written to the security event log as `ai.request` and to the `ai_interactions` table with the model, the provider, the token counts and a fingerprint of the question and answer — never their text. Token use is counted per person, per session and per page in `ai_usage`, which is what the daily budget is read from. Refused and flagged questions are recorded as `ai.input.rejected` and `ai.input.flagged` with the rule that matched.

## Your Anthropic API key

Read only from the environment; never sent to the model, written to the database, or included in a log line.
