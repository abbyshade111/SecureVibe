# Talking to other services

This app can only call other web services through one function, and only to hosts you explicitly allow.

## Currently allowed

*(none — OUTBOUND_ALLOWED_HOSTS is empty, so the app cannot call out to anything)*

## Rules that always apply

- Only `https://` and `http://` addresses; credentials embedded in the URL are refused.
- Redirects from the other service are never followed automatically.
- Every call times out after 10 seconds and stops reading after 1 MB.
- Certificate checks are never turned off.
- After 5 failures in a row, calls to that host pause for 30 seconds (a "circuit breaker") so one broken service cannot slow the rest of the app down.
- A blocked or failed call is written to the security event log (`outbound.blocked`, `outbound.failure`, `breaker.open`).

To allow a new host, add it to `OUTBOUND_ALLOWED_HOSTS` in `.env` (comma-separated, `host` or `host:port`) and restart the app.
