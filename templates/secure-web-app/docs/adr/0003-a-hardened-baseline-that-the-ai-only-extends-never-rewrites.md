# ADR 3: A hardened baseline that the AI only extends, never rewrites

Status: accepted (baseline template decision)

## Context

Security controls implemented once, tested once, and evidenced mechanically are more trustworthy than controls re-generated by a language model for every app.

## Decision

Core security files (session, CSRF, headers, password, authorization, the route registry) are protected paths; the generator adds features that follow the same registry and conventions shown in `src/features/_example/`.

## Consequences

A generated app inherits every fix made to the baseline template; the compliance report can credit a control mechanically because the code that implements it did not change.
