# What is logged

Two things are written for every security-relevant action: a structured log line, and a row in a tamper-evident security event table.

## Where

| What | Detail |
| --- | --- |
| Application log | JSON lines, error level and above, at `DATA_DIR/app.log` |
| Security event log | `audit_log` table in the database — append-only and hash-chained (each row includes the hash of the row before it), kept for at least 400 days |
| Checking the security event log | Run `npm run audit:verify` — it recomputes every hash and reports the first row that does not match |

## What is never written to a log

Passwords, one-time codes, tokens, API keys, cookies and any field an entity marks `sensitive` are replaced with `[redacted]` wherever they would otherwise appear, at any depth. A session is only ever identified by the first 8 characters of its hash.

## Security events

| Event | Default outcome | What it means |
| --- | --- | --- |
| `auth.login.success` | success | Someone signed in. `factor` says whether a one-time code was used. |
| `auth.login.failure` | failure | A sign-in attempt failed (`reason`: wrong password, unknown account, disabled, locked, expired bootstrap). |
| `auth.logout` | success | Someone signed out. |
| `auth.password.changed` | success | A user changed their password. |
| `auth.password.reset.requested` | success | A password reset link was requested (logged whether or not the account exists). |
| `auth.password.reset.completed` | success | A password was reset with a valid link. |
| `auth.mfa.enrolled` | success | A user set up a one-time code app. |
| `auth.mfa.disabled` | success | A user (or an admin) removed one-time codes from an account. |
| `auth.mfa.failure` | failure | A one-time code was wrong or reused. |
| `auth.reauth.success` | success | A user confirmed their password before a sensitive change. |
| `auth.reauth.failure` | failure | Password confirmation before a sensitive change failed. |
| `auth.lockout` | blocked | An account was temporarily locked after repeated failed sign-ins. |
| `authz.denied` | blocked | Someone tried to open a page or record they are not allowed to use. |
| `session.revoked` | success | Sessions were ended (`count`, `reason`). |
| `validation.rejected` | blocked | A request was rejected because its input was not valid. |
| `csrf.rejected` | blocked | A form or API request failed the cross-site request check. |
| `ratelimit.hit` | blocked | A rate limit was reached (`bucket`). |
| `upload.rejected` | blocked | An upload was refused (`reason`). |
| `upload.stored` | success | A file was stored. |
| `download.denied` | blocked | Someone tried to download a file they do not own. |
| `admin.user.created` | success | An administrator created an account. |
| `admin.user.disabled` | success | An administrator disabled an account. |
| `admin.user.deleted` | success | An administrator deleted an account. |
| `admin.user.mfa_reset` | success | An administrator removed one-time codes from an account (`reason` recorded). |
| `admin.user.sessions_revoked` | success | An administrator signed a user out everywhere. |
| `data.exported` | success | A user downloaded a copy of their data. |
| `data.deleted` | success | A user account and its data were deleted. |
| `ai.request` | success | A request was sent to the AI model (token counts, hashes — never the text). |
| `ai.input.flagged` | success | AI input matched a suspicious pattern but was allowed (`rule`). |
| `ai.input.rejected` | blocked | AI input was refused (`reason`). |
| `ai.output.rejected` | blocked | An AI answer was withheld (`reason`). |
| `ai.moderation.decision` | success | The content moderation check made a decision. |
| `ai.budget.exceeded` | blocked | A user reached their daily AI budget. |
| `ai.killswitch.toggled` | success | An administrator switched the AI assistant on or off. |
| `outbound.blocked` | blocked | The app refused to contact a host that is not on the allow-list (`host`). |
| `outbound.failure` | failure | A call to an external service failed (`host`). |
| `breaker.open` | blocked | Calls to an external service were paused after repeated failures (`host`). |
| `error.unhandled` | failure | An unexpected error happened (`reqId` links to the log line). |
| `config.startup` | success | The app started (`algorithm` for password hashing, `tlsMode`). |
