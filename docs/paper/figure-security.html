3. sv: where that reach stands

Every requirement in each framework, from docs/COVERAGE.md at c5ae4f9. "Can settle" means a check can mark it checked or needing attention: usually one automated check on part of the requirement, not a pass. The Secure by Design checklist asks about policy and design, which no check can settle, by design.
