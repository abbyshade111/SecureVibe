How the faults the tests missed were caught

Every fault below passed the automated suites. Each was caught another way: by a person using the software, by one AI session reviewing another's merged work, by breaking a guard on purpose to see whether anything noticed, by v1's evaluation harness, or by accident. One dot per fault written down in the repository.
