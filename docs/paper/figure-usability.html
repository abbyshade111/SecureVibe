sv: getting to step one (7), and VS Code (2)

Found by trying it as the owner would, the same day. The walk-through itself was short; getting to its first step was not.

What stopped itWhere it stands
Step one was "install Rust": sv had to be built from sourceA container image, published from CI (#205, #208); a download per platform is still to come
A built sv cannot be moved: it reads its data files from the folder it was built inRecorded; the container carries its data with it
The README's MCP command (claude mcp add) does not exist in the desktop appA .mcp.json in the app's folder works instead (walk-through, #218)
The --root folder had to exist already, and nothing said so until the tool was refusedRecorded
The starter manifest answered "no" to every capability: "the most dangerous line in the product"Starter answers now start unanswered (#252)
The deepest checks need DockerSaid plainly in the walk-through
The README said four MCP tools when there were sixRecorded
VS Code: a hand-made .vscode/mcp.json was not listedThe guide has VS Code write the file itself (#235)
VS Code: 9 of 13 notes written by the tool were reported as the owner'sNotes say who wrote them (#239), and a person can confirm what the tool wrote (#242)
