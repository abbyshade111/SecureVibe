What coordinating several AI sessions cost, and what it bought

Several Claude Code sessions worked on the same repository at once. Keeping them out of each other's way took a quarter of all changes, and two in five in the last week. The friction sat in whichever file every change wrote to: the backlog, then the design document. Reading each other's work found more faults than failing tests did, and from 28 September a session from another project sent work in as well. The full account is COORDINATION.md.
