What coordinating several AI sessions cost, and what it bought

Several Claude Code sessions worked on the same repository at once. Keeping them out of each other's way took a fifth of all changes, and most of the friction was in the one file they used to coordinate. Reading each other's work found more faults than failing tests did. The full account is COORDINATION.md.
