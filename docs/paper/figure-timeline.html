How the project unfolded, 16–27 September 2026

Two versions over twelve days: v1, which builds an app from a fixed template and checks it, and sv, which checks an app written in any language by anyone. On 26 September sv replaced v1 at the top of the repository. The detail is in TIMELINE.md.
