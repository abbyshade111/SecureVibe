# ADR-063: StackVet's logo is the code bracket, in terracotta

**Status:** accepted, 8 October 2026, by the owner, in the pull request that adds the files. Written by session
securevibe-e2.

**Governs:** `docs/brand/**`. A pull request that changes the logo, its colors, or its font changes this record
too, or says in its description why it does not (`docs/adr/README.md`).

## Context

On 8 October 2026 the owner found another product named SecureVibe, in the same field (security reports for
vibe-coded projects), and chose a new name, StackVet, for which the rename's own record speaks. For the repository's
new name they asked for logo options. Six were drawn on a design canvas: a check over a stack, an honest checklist
with one item unticked, a lens on the stack, a check inside code brackets, a stacked "S", and a paw for the "vet"
pun. Purple was left out on purpose, since it is the other SecureVibe's color, and so were shields and "approved"
stamps, since StackVet never says an app is secure and a stamp would say it for it.

## Decision

The owner chose the code bracket ("I like the code bracket option"), then, of six colors, terracotta ("I like the
terracotta one"). The logo is a check mark inside square brackets, with the name in JetBrains Mono Bold and "vet" in
the accent color:

| Use | Light background | Dark background |
| --- | --- | --- |
| Accent ("vet" and the check) | `#C2410C` | `#FDBA74` |
| Brackets and "stack" | `#14201C` | `#F3F4EF` |
| Dark background | | `#12201B` |

The letters are drawn as outlines from the font, so the logo looks the same whether or not the font is installed.
JetBrains Mono is free to use under the SIL Open Font License.

## Considered

The other five drafts, above, and five other colors (amber, teal, green, blue, and one color only). Amber and teal
were the session's suggestions; the owner preferred terracotta, which also stands apart from the blues and purples
most security tools use.

## Costs

The bracket reads as a developer's symbol, which may feel less friendly to the people StackVet is for than the
warmer drafts would have. The accent on white passes the contrast a person needs to read normal-size text
(about 5.2 to 1); the dark background's accent passes easily.

## As built

`docs/brand/` holds the logo light and dark, the mark alone, a browser-tab icon, a phone icon, and the 1280 by 640
image GitHub shows when the repository is shared, each as SVG and PNG, with a README on which file goes where, and
`docs/brand/source/` the two scripts that made them. Putting them to work (the README, the preview image, the sites,
the container image) is the backlog item "Put the StackVet logo to work once the rename has landed".
